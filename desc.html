Description of Gender Predictor:

This section of the website uses a pre-trained model to determine if the person in the image is a male or female. Data: https://bcsiriuschen.github.io/CARC/t


Description of Training:

This section of the website is a 'train your own AI' type of thing. I wanted to show the AI's process of training, but realized that training it would take a long time, meaning I can't train the model on the spot for the user to see. So, I created this section of the website that lets the user upload some images to train an AI using the REPL. Obviously, the user probably won't be able to train a really good AI, but this is the best way I could think of to show how the AI works.
