Description of Male vs Female Classifier:

This section uses an upgraded pre-trained neural network (48×48 resolution, 2,304 inputs) to classify face images as Male or Female with 83.5% accuracy on unseen holdout test faces. It was pre-trained using the CARC face dataset:
https://bcsiriuschen.github.io/CARC/

GitHub Repository: github.com/Carson-Cheung/binary-classification-ai


Description of Training (Class A & Class B):

This section of the website is a 'train your own AI' type of thing. I wanted to show the AI's process of training, but realized that training it would take a long time, meaning I can't train the model on the spot for the user to see. So, I created this section of the website that lets the user upload images to train a custom binary classifier (Class A and Class B) right in the browser. Obviously, the user probably won't be able to train a really good AI with just a few pictures, but this is the best way I could think of to show how the AI works.
